# Terminal Text / Syntax Reveal — Text Reference

## Purpose
Terminal-inspired text treatment representing the engineering side of the portfolio.

## Portfolio role
**Engineering identity**

## Visual language
- Monospace typography
- Command prompt
- Syntax highlighting
- Small terminal chrome
- Restrained cursor
- Progressive text reveal

## Animation
```text
command prompt → typing → output reveal → cursor → complete state
```

Trigger when the terminal enters the viewport.

## Optional sound
Sound may be supported, but must be **off by default**, user-controlled, and never required for comprehension.

## Accessibility
Complete terminal content must exist semantically. With reduced motion, show it immediately.

## Constraints
Keep it compact and metaphorical. Do not simulate dangerous commands or pretend it is a live shell.

**Semantic meaning: Terminal text = Engineering.**
