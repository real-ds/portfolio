## Shared motion character
The portfolio should feel:
- smooth
- restrained
- cinematic
- editorial
- technically precise

Suggested base easing:
`cubic-bezier(0.22, 1, 0.36, 1)`

## Reduced motion
Every reference must have a non-animated equivalent. Animation is enhancement, never the content itself.
